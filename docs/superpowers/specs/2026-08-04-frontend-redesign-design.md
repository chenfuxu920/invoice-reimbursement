# 前端界面重设计 · 财务工作台

日期：2026-08-04
状态：已批准（用户确认整体批准）

## 背景与目标

发票报销助手（Tauri 2 + Vue 3 + Tailwind 4）完整前端重设计。当前界面为 Tailwind 灰底白卡 + 蓝色主色的朴素风格，含 emoji 图标与 `alert()` 系统弹窗。

用户确认的目标（四项全选）：
1. 更好看、有质感
2. 操作流程更顺
3. 信息更清晰
4. 更像专业桌面应用

硬性约束：保持中文界面；兼容窄窗口。核心功能与数据模型不变；组件继续用 Tailwind 手写（无 UI 库）。

## 选定的视觉方向：财务工作台（方向 A）

石墨灰中性底 + 靛蓝主色，像财务软件/票据归档柜：专业、可信、高效。Operate 模式，信息层级与任务完成优先于表达。

## 1. 整体布局（App 壳层）

- **左侧导航栏**：宽 56px（仅图标）↔ 展开 200px（图标+文字）。导航项：首页 / 导入 / 匹配 / 导出；底部独立放「调试工具」。窄窗口（<lg）自动折叠为图标条。
- **顶部栏**：左侧当前页面标题；右侧全局状态（OCR 在线指示点 + 版本号）。
- **流程步进器**：内容区顶部固定 3 步指示条（导入 → 匹配 → 导出）。分趟是导出页内的子步骤，不占独立步。根据真实数据状态自动点亮：有发票+账单 → 匹配步可点；有匹配 → 导出步可点。当前步高亮，可直接点击跳转。窄窗口允许横向滚动。

## 2. 视觉语言

- **配色**（Tailwind 4 `@theme` 扩展 CSS 变量）：
  - 背景：中性灰微渐变（gray-50 → gray-100），桌面质感而非纯平
  - 卡片：白色 + 1px 边框（gray-200）+ 轻阴影（shadow-sm）
  - 主色：靛蓝 indigo-600（操作、选中、链接、主按钮）
  - 状态语义色：emerald-500=成功/就绪、amber-500=待调整、red-500=错误/失败、gray-400=未开始/禁用
  - 原则：彩色只表达状态，不用于装饰
- **排版**：系统字体栈（`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif`）；标题 font-semibold；金额数字 `tabular-nums` 右对齐。
- **图标**：统一 1.5px stroke 风格内联 SVG（16/20px），全部替换现有 emoji。
- **圆角/密度**：桌面紧凑密度（行高 32-40px）；卡片圆角 10px；按钮圆角 8px。

## 3. 组件规范

| 组件 | 规范 |
|---|---|
| Button | primary（靛蓝实底）/ secondary（白底描边）/ ghost / danger 四态；loading 态带 spinner；禁用态 opacity-50 |
| 状态徽章 | 语义色圆点 + 文字（已就绪/待匹配/待调整/失败），配色与状态语义一致 |
| Table | 表头浅灰底、行 hover、金额右对齐 tabular-nums |
| Card | 标题 + 操作区 + 内容区；hover 轻提升（shadow 增强） |
| Modal | 居中、标题 + 描述 + 页脚按钮、ESC/遮罩关闭 |
| Empty state | 带图标 + 文案 + 指向下一步的操作按钮 |
| Toast | 右上角淡入淡出，3 秒自动消失；成功/失败/信息三色；替换全部 `alert()` |

## 4. 各页面设计

| 页面 | 要点 |
|---|---|
| 首页 | OCR 引擎状态卡（在线绿点/离线红点 + 模型下载 + 下载地址设置）→ 4 统计卡（发票/账单/匹配/分趟）→ 流程引导大卡（按数据状态提示"下一步该做什么"）→ 快捷操作 |
| 导入 | 发票区：大拖拽卡 + 「＋手动添加空发票」；账单区：导入器 + 下载指引 + 账单明细表；解析失败统一错误状态区（手动填写/重试/移除） |
| 匹配 | 顶部 3 统计（已匹配/未匹配发票/未匹配支付）→ 已匹配卡片列表 → 未匹配发票列表（含分类选择）→ 未匹配支付折叠区 |
| 导出 | 顶部摘要（已匹配/未匹配发票/未匹配支付）→ 分趟工具栏（出发城市重匹配）→ 一键导出全部 → 分趟卡片垂直列表（时间线感）→ 待调整区（琥珀色调） |
| 调试 | 移入侧栏底部「调试工具」，样式与其他页面统一 |
